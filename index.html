Enterprise Relational Database Schema Built with SQL Server & T-SQL
Architectural Focus: Complete 3NF relational schema with ACID transactions, stored procedures, triggers, audit tables, and index optimization.

Designed and implemented a complete Library Management System database using Microsoft SQL Server and T-SQL.
